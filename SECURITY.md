# Security policy

SCOPL contracts control real assets on Robinhood Chain. Do not report a
suspected vulnerability in a public issue or disclose an exploit before the
maintainers have had time to respond.

Use the repository's private GitHub security-advisory channel. Include the
affected contract and function, impact, prerequisites, reproduction steps, and
any proposed mitigation. Do not interact with deployed contracts beyond the
minimum read-only work needed to validate a report.

There is currently no public bug-bounty promise. Acknowledgement or payment
must not be assumed without a separate written agreement.
